# MUST Capacity Alerter

MUST Capacity Alerter helps students monitor closed courses and receive a WhatsApp notification when a seat becomes available.

The application allows authenticated users to:

- Create a course capacity request
- View their submitted course requests
- Edit course request details
- Start or stop capacity alerts
- Receive notifications when capacity becomes available

## Tech Stack

- React
- Vite
- React Router
- Clerk authentication
- JavaScript
- CSS
- REST API backend
